🧠 Cálculo de Outs

Este proyecto utiliza outs ajustadas por textura del board, siguiendo un enfoque heurístico y pedagógico.

Las outs se calculan por componentes independientes (overcards, proyectos de color, proyectos de escalera) y se ajustan dinámicamente según:

textura del board

mesa emparejada / doblada

presión de color y escalera

El objetivo del sistema no es calcular equity exacta, sino entrenar la identificación de proyectos y la toma de decisiones (incluyendo reconocer spots sin outs y elegir fold).
